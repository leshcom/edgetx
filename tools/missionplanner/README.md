# CRSF RC Override — плагін Mission Planner

Пульт EdgeTX у режимі **USB RC OUT** віддає на COM-порт стандартні кадри CRSF
`RC_CHANNELS_PACKED`. Плагін читає їх і пересилає канали на підключений борт
повідомленнями MAVLink `RC_CHANNELS_OVERRIDE`.

```
TX16S ──USB (CRSF)──► Mission Planner + плагін ──MAVLink RC_CHANNELS_OVERRIDE──► борт
```

Плагін також приймає CRSF від будь-якого CRSF/ELRS-приймача, підключеного до ПК
через USB-UART (швидкість 420000).

## Встановлення

1. Закрийте Mission Planner.
2. Скопіюйте `CrsfRcOverridePlugin.cs` у папку `plugins` поруч із `MissionPlanner.exe`
   (зазвичай `C:\Program Files (x86)\Mission Planner\plugins\`).
3. Запустіть Mission Planner: він сам скомпілює плагін при старті.
   Помилки компіляції видно в меню **Help → Plugins** (або в логах).

## Використання

1. Підключіть пульт кабелем і виберіть **USB RC OUT**.
2. У Mission Planner підключіться до борту як звичайно.
3. **Flight Data → правий клік по карті → CRSF RC Override...**
4. Виберіть COM-порт пульта і натисніть **Відкрити**. Мають з'явитися значення каналів і ~250 кадр/с.
5. Поставте галочку **Надсилати RC override на борт**.

Налаштування у вікні:
- **Каналів** — скільки перших каналів переписувати (решта лишається за RC-приймачем борту).
- **Частота** — як часто надсилати override на борт (за замовчуванням 50 Гц; пульт шле CRSF на 250 Гц,
  плагін бере з них найсвіжіші значення; для повільних
  телеметрійних радіо, наприклад SiK 57600, краще 10–20 Гц).

## Безпека

- Якщо кадри CRSF зникли більше ніж на 200 мс (витягли кабель, перемкнули режим USB),
  плагін припиняє override і явно повертає канали RC-приймачу борту.
- Те саме відбувається при знятті галочки й при закритті Mission Planner.
- Якщо обірвалася телеметрія, борт тримає останні значення override протягом
  `RC_OVERRIDE_TIME` секунд (за замовчуванням 3), потім повертається до RC-приймача.
  Налаштуйте цей параметр під свій апарат.
- `MAV_GCS_SYSID` на борту має збігатися з SYSID Mission Planner (за замовчуванням 255).
- Не вмикайте одночасно штатний **Joystick** Mission Planner: обидва надсилатимуть override.
